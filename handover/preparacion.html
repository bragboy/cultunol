Preparación antes de nuestra llamada

Siete pasos para tener tu ordenador listo. Así en la llamada vamos directos a publicar tu web y a enseñarte a usar Claude.

TiempoUnos 60 minutos, con calma
NecesitasTu ThinkPad, internet y tu móvil
CosteClaude Pro (20 USD/mes) en lugar de ChatGPT Plus
Usa tu Gmail personal para Claude y GitHub, no info@cultunol.com. Así estas cuentas son tuyas para siempre, pase lo que pase con el dominio o Google Workspace.
Antes de empezar: no tienes que entender nada de lo que escribes, solo copiarlo tal cual. Si un paso falla, haz una captura de pantalla del error y mándamela por WhatsApp. No pasa nada.
Cómo copiar y pegar comandos: selecciona el texto de los recuadros oscuros de este PDF y cópialo con Ctrl + C. En la terminal WSL (la ventana negra) se pega con clic derecho (o Ctrl + Shift + V). Después pulsa Enter. Copia un recuadro cada vez.
1

Cambia ChatGPT Plus por Claude Pro

5 min
  1. En chatgpt.com: tu foto (abajo a la izquierda) → Configuración → Cuenta → Gestionar la suscripción → Cancelar. Sigue funcionando hasta el final del mes pagado y luego pasa al plan gratuito.
  2. Entra en claude.ai → Continuar con Google con tu Gmail personal (no el correo de Cultuñol).
  3. Pulsa Upgrade y elige el plan Pro. Este plan incluye Claude Code, que instalaremos en el paso 6.
2

Instala WSL en tu Windows

15 min + reinicio

WSL es una herramienta gratuita de Microsoft que se instala dentro de tu Windows. Te da una ventana de comandos (la "terminal WSL") donde trabajaremos con tu web.

  1. Pulsa la tecla Windows, escribe PowerShell. Sobre "Windows PowerShell" haz clic derecho → Ejecutar como administrador → Sí.
  2. En la ventana azul, pega esto y pulsa Enter:
wsl --install
  1. Cuando termine, reinicia el ordenador.
  2. Al volver, se abre sola una ventana negra: es la terminal WSL. Sigue siendo tu Windows; es solo una ventana más. Si no se abre, búscala en el menú Inicio: aparece con el nombre Ubuntu (es el nombre de la app de WSL). La primera vez tarda unos minutos.
  3. Te pide un nombre de usuario: escribe uno en minúsculas y sin espacios, por ejemplo monica.
  4. Te pide una contraseña dos veces. Al escribirla no se ve nada: es normal. Apúntala, la necesitarás a veces.
Si sale un error que menciona "virtualization" o "virtualización", para aquí y mándame una captura. Se arregla en la llamada.

Desde aquí, todos los comandos se pegan en la terminal WSL.

3

Crea tu cuenta de GitHub

5 min

GitHub es donde vivirá tu web. Publicará tu página gratis cada vez que hagas un cambio.

  1. Entra en github.com/signup.
  2. Correo: tu Gmail personal. Crea una contraseña y un nombre de usuario corto (por ejemplo monicafiestas).
  3. Resuelve el pequeño puzzle, escribe el código que te llega por correo y elige el plan Free (gratis).
  4. Si te pide activar la verificación en dos pasos, hazlo con la app Google Authenticator del móvil y guarda los códigos de recuperación en un lugar seguro.
4

Prepara la terminal WSL

5 min

Pega este recuadro. Te pedirá la contraseña de WSL (la del paso 2):

sudo apt update && sudo apt install -y git curl
5

Conecta tu ordenador con GitHub (clave SSH)

10 min

Una clave SSH es como una llave de casa: permite que tu ordenador entre en GitHub sin escribir la contraseña cada vez.

  1. Crea la llave. Cuando haga preguntas, pulsa Enter sin escribir nada (tres veces):
ssh-keygen -t ed25519 -C "thinkpad"
  1. Copia la llave pública al portapapeles de Windows:
cat ~/.ssh/id_ed25519.pub | clip.exe
  1. En GitHub: tu foto (arriba a la derecha) → Settings → SSH and GPG keys → New SSH key. En "Title" escribe ThinkPad, en "Key" pega con Ctrl + V y pulsa Add SSH key.
  2. Comprueba que funciona. Si pregunta "Are you sure…?", escribe yes y Enter:
ssh -T git@github.com
Debe decir: Hi tu-usuario! You've successfully authenticated… Si lo ves, ¡perfecto!
6

Instala Claude Code y mise

10 min

Claude Code es el asistente con el que cambiarás tu web hablando en español. mise instala automáticamente las herramientas que necesita tu web.

curl -fsSL https://claude.ai/install.sh | bash curl https://mise.run | sh echo 'eval "$(~/.local/bin/mise activate bash)"' >> ~/.bashrc
  1. Cierra la terminal WSL y vuelve a abrirla.
  2. Escribe claude y pulsa Enter. Elige iniciar sesión con tu cuenta de Claude (Pro). Te dará un enlace: ábrelo en el navegador (con Ctrl + clic o copiándolo), autoriza y, si te da un código, pégalo en la terminal WSL.
  3. Cuando veas que Claude te saluda, sal escribiendo /exit.
7

Comprobación final y envíame esto

2 min

Pega este recuadro entero:

git --version; mise --version; claude --version; ssh -T git@github.com

Deben salir tres versiones y el mensaje "successfully authenticated". Después mándame por WhatsApp:

  1. Una captura de pantalla de esa ventana.
  2. Tu nombre de usuario de GitHub. Con él te paso tu web a tu cuenta.
